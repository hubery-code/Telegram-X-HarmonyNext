# 计划与架构审计入口

本目录是所有开发 AI、检查 AI 和架构 AI 的计划入口。

读取顺序：

1. [迁移实施与架构计划](HARMONY_NEXT_MIGRATION_PLAN.md)：上位架构、阶段 Gate、工作包规则和质量标准。
2. [2026-09-14 实施审计](IMPLEMENTATION_AUDIT_2026-09-14.md)：当前代码基线、已确认偏差、阻断项和 Quality Recovery Sprint。
3. [工作协调看板](../../PROGRESS.md)：当前工作包认领和执行状态。

规则：

- 仓库内版本是唯一有效版本；下载目录中的文件只作为历史备份。
- 新 AI 开工前必须先读取以上三份文件，不得只依据 README 的功能列表判断进度。
- 审计明确的 P0 未关闭前，暂停普通新功能和对外测试包分发。
- Gate、Feature Matrix 和 Accepted 状态只能由架构负责人依据可重跑证据更新。
