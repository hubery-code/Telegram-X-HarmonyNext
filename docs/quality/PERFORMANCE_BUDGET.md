# Performance Budget（性能预算）

> 来源：计划 §14.2/§14.3。**数值在 G0/G1 目标真机实测后冻结；实现 AI 无权自行放宽。**
> 相对批准基线的回退 >10%（P95）即阻断。

## 性能（§14.2）

| 指标 | 预算 | 测量条件 |
|---|---|---|
| 冷启动到可交互（缓存数据） | P95 ≤ 2.5 s | 目标真机，冷启动 |
| 热恢复到可交互 | P95 ≤ 0.8 s | 后台召回 |
| NAPI UI 线程同步工作 | 单次 ≤ 4 ms；禁止同步等待网络/磁盘/TDLib | trace |
| 会话/消息列表卡顿帧占比 | < 5%，不得连续明显冻结 | 滚动基准 |
| 文本聊天 30 分钟前台 RSS | 建议 ≤ 250 MB | 稳态 |
| 浏览 100 张图片峰值内存 | 建议 ≤ 450 MB；退出页面后明显回落 | 峰值 |
| 启动/内存/帧耗 P95 回退 | > 10% vs 批准基线 = 阻断 | 回归对比 |
| 包体增长 | 超工作包预算必须解释并审批 | 每次构建 |

## 稳定性（§14.3）

| 指标 | 预算 |
|---|---|
| 核心 smoke 连续无崩溃 | 100 次 |
| Beta 前随机操作（Monkey/等价物） | 8 小时或 ≥10,000 次，无崩溃、无数据损坏 |
| 稳态内存增长斜率 | 建议 < 1 MB/小时 |
| Beta 7 天 crash-free session | ≥ 99.8% |
| Beta 7 天 freeze/ANR-free session | ≥ 99.9% |
| native leak / use-after-free / double-free | 零容忍 |

## 基线与测量

- 基线测量工具与真机未冻结（待 DEVICE_MATRIX.md 用户输入）。
- CI 侧先记录构建产物大小与构建时长趋势（GOV-006 扩展），真机指标从 G1 开始录入。
- 性能证据格式：trace/perf 产物路径 + commit + 设备型号，按 §17.3 机器可读证据登记。
