## 设计决策

- **GIF 搜索为本地过滤**：`gifSearchQuery` 在 reducer 中仅更新状态，`getActiveGifs()` 方法在 UI 层做 `caption.includes(query)` 过滤；后续可替换为远端 Tenor API 调用。
- **2 列 Grid**：GIF 卡片宽度约 50%，高度固定 100vp，避免异步加载宽高导致的布局抖动。
- **`GIF` 角标**：每个卡片右下角叠加半透明蓝色角标，与图片叠加实现 GIF 视觉标识；实际动画渲染需 Image 组件支持 AnimatedImage。
- **Recent 置顶去重**：与 Emoji/Sticker 保持一致的 32 条上限置顶去重逻辑。
