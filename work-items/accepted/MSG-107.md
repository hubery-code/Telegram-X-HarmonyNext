### 2. 特性层模型与契约
- `feature/chat/src/main/ets/model/LinkPreviewInfo.ets` [NEW]：
  - 声明纯 ArkTS 不可变数据模型 `LinkPreviewInfo`；
  - 封装 `url`, `displayUrl`, `siteName`, `title`, `description`, `author`, `showAboveText`, `thumbnailPath`, `fileId`, `isPhoto`, `isLargeMedia`, `showMediaAboveDescription`, `mediaWidth`, `mediaHeight` 与 `aspectRatio` 计算属性；
  - 提供 `hasContent()` 纯函数守卫；
- `feature/chat/src/main/ets/model/MessageItem.ets`：
  - 扩展 `readonly linkPreview: LinkPreviewInfo | null = null` 属性并保持构造器向后兼容；
- `feature/chat/src/main/ets/Index.ets`：
  - 导出 `LinkPreviewInfo`。

### 3. 协调调度与缩略图自动下载
- `feature/chat/src/main/ets/coordinator/ChatCoordinator.ets`：
  - 新增纯函数 `resolveLinkPreviewInfo(linkPreview: LinkPreview | null): LinkPreviewInfo | null`；
  - 解析 Article, Photo, Video, Animation, App, Document 等媒体类型的主图与缩略图 `fileId`，提取真实媒体宽高；
  - 针对大图预览通过 `chooseDisplaySize(photo.sizes)` 选取合适的高清档位；
  - 联动 `FileRegistry` 查询本地路径，未命中时调度 `requestMediaDownload(fileId, 2)` 自动拉取；
  - 在 `mapMessageToItem` 中将 TDLib `MessageText.link_preview` 映射为 `LinkPreviewInfo` 并绑定至 `MessageItem`。

### 4. UI 渲染与交互组件
- `feature/chat/src/main/ets/pages/ChatPage.ets`：
  - `messageRowKey`：将 `linkPreview` 状态（URL、站点名、标题、描述、缩略图物理路径、大图标记、上下位置、排版方向与宽高比）纳入签名，确保异步下载完成后 LazyForEach 单行局部刷新；
  - 气泡布局分流：根据 `item.linkPreview.showAboveText` 分别在正文文本上方或下方渲染 `@Builder LinkPreviewBubble`；
  - 实现 `@Builder LinkPreviewBubble`：
    - 左侧 3vp Telegram 蓝竖条（`T.colors.accent`，圆角 1.5vp），通过弹性容器贯穿整个预览卡片顶部到底部；
    - 顶部 `siteName`（12fp，Bold，`T.colors.accent`）；
    - 主体 `title`（14fp，Bold，`T.colors.chatText`，最大 2 行截断）；
    - 摘要 `description`（13fp，Regular，`T.colors.textSecondary`）；
    - 缩略图呈现：小图位于右侧 52x52vp（Cover 裁剪，`T.radius.sm` 圆角）；大图位于卡片内按原生比例自适应渲染（`aspectRatio`，最大高 220vp，不裁切人物面容）；
    - 响应 `show_media_above_description` 动态排列大图与描述相对位置；
    - 点击卡片调用 `openLink(preview.url)` 打开系统默认浏览器。
