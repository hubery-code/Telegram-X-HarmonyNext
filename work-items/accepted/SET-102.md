## 实际修改

### 1. `core/design_system` 全局主题契约与运行时管理
- `core/design_system/src/main/ets/Theme.ets`：
  - 导出 `ThemePreference`: `'system' | 'light' | 'dark'`；
- `core/design_system/src/main/ets/ThemeManager.ets`：
  - 新增 `ThemeManager` 运行时协调器，100% Kit-free 纯 ArkTS 领域逻辑；
  - 提供 `setPreference(pref)`、`getPreference()`、`setSystemMode(mode)`、`setSystemColorMode(mode)`、`getSystemMode()`；
  - 提供纯函数 `resolveTheme(preference, systemMode, fontScale)` 与 `resolveThemeMode(preference, systemMode)`；
  - 支持 `subscribe(listener, notifyImmediately)` 响应式监听主题变化与 `unsubscribe(listener)`；
  - 提供 `ThemeManager.getInstance()` 单例、`themeManager` 实例导出以及 `reset()` 测试隔离方法；
- `core/design_system/src/main/ets/Index.ets`：
  - 统一导出 `ThemePreference`、`ThemeListener`、`ThemeManager`、`themeManager`、`resolveTheme`、`resolveThemeMode`；
- `core/design_system/src/test/ThemeManager.test.ets` & `List.test.ets`：
  - 新增 13 组单元测试，覆盖浅色/深色/系统模式解析、回退机制、响应式订阅退订、单例生命周期重置与字号缩放。

### 2. `feature/settings` 主题切换交互、状态驱动与持久化联动
- `feature/settings/src/main/ets/contract/SettingsUiState.ets`：
  - `SettingsThemeMode` 对齐 `@tgx/core-design-system` 的 `ThemePreference`；
  - `SettingsUiState.initial(themeMode)` 支持纯函数入参并保持 `system` 默认值；
- `feature/settings/src/main/ets/reducer/SettingsReducer.ets`：
  - `case 'changeThemeMode'`：同步更新全局 `ThemeManager.getInstance().setPreference(...)`；
  - 安全更新 `AppStorage`（`themeMode` 与 `themePreference` 键值），纯单测环境静默容错；
  - 保持纯 MVI 架构，输出 `ShowToastEffect` 反馈；
- `feature/settings/src/main/ets/coordinator/SettingsCoordinator.ets`：
  - 构造时对齐 `ThemeManager.getInstance().getPreference()`；
  - 订阅 `ThemeManager` 变更，实现系统色彩模式或外部主题偏好变更时自动同步 `SettingsUiState`；
  - `destroy()` 完整解绑主题订阅；
- `feature/settings/src/main/ets/pages/SettingsPage.ets`：
  - 新增 `@State private effectiveTheme: Theme` 与 `ThemeManager` 响应式订阅；
  - 完善 `ThemeCardView`：提供 `System` / `Light` / `Dark` 三态分段切换按钮，高亮选中项（`accent` 背景 + `textOnAccent` 文案 + 加粗字重）；
  - 增加当前生效模式辅助摘要 `getThemeModeSummary`（如 `System (Light)` / `System (Dark)`）；
  - 消除非法 token `backgroundElevated`，安全对齐为 `surfaceVariant`；
- `feature/settings/src/test/SettingsReducer.test.ets`、`SettingsTheme.test.ets` & `List.test.ets`：
  - 扩充 11 组针对主题模式切换、ThemeManager 同步与状态不变性测试。
