## 实际修改

### 1. `core/common` 国际化运行时与字典管理契约
- `core/common/src/main/ets/Lang.ets`：
  - 导出 `LanguagePreference`: `'system' | 'en' | 'zh'`；
  - 导出 `SupportedLanguage`: `'en' | 'zh'`；
  - 提供纯函数 `resolveLanguage(preference, systemLanguage)`；
  - 提供 `formatString(template, args)`，同时支持 `{0}`/`{1}` 占位符与 `%s`/`%d` 格式化；
  - 实现 `Lang` 管理单例与导出 `lang` 常量：
    - 内置通用业务词条中英字典（Settings, General, Language, Appearance, Theme, Light, Dark, System, Follow System, Storage, Clear Cache, Chats, Messages, Cancel, Done, Delete, Edit, Reply, Copy, Forward, Pin, Unpin, Save, Search, Send, Photos, Files, Notifications 等）；
    - 支持 `getString(key, ...args)` 与快捷别名 `t(key, ...args)`；
    - 支持 `subscribe(listener)` 与 `unsubscribe(listener)` 响应式监听；
    - 提供 `registerTranslations` 扩展词条字典；
    - 提供 `reset()` 保证单元测试隔离性；
- `core/common/src/main/ets/Index.ets`：
  - 统一导出 `Lang`、`lang`、`LanguagePreference`、`SupportedLanguage`、`LanguageListener`、`resolveLanguage`、`formatString`；
- `core/common/src/test/Lang.test.ets` & `List.test.ets`：
  - 新增 9 组 100% 覆盖单元测试，覆盖系统语言回退、占位符替换、单例状态重置、订阅通知与字典查询。

### 2. `feature/settings` 语言切换、状态管理与 UI 联动
- `feature/settings/src/main/ets/contract/SettingsIntent.ets`：
  - 支持 `ChangeLanguage` 与 `SetLanguage` intent；
- `feature/settings/src/main/ets/contract/SettingsUiState.ets`：
  - 扩充 `languagePreference: LanguagePreference` 与 `languageCode: string` 状态字段；
- `feature/settings/src/main/ets/reducer/SettingsReducer.ets`：
  - 处理 `changeLanguage` / `setLanguage`：
    - 同步更新全局 `Lang.getInstance().setLanguage(pref)`；
    - 联动更新 `AppStorage`（`appLanguage` / `languagePreference`），单测环境安全容错；
    - 触发 `ShowToastEffect` 轻提示；
- `feature/settings/src/main/ets/coordinator/SettingsCoordinator.ets`：
  - 构造时根据 `Lang.getInstance()` 初始化语言偏好；
  - 订阅 `Lang` 变更并及时同步至 `uiState`；
  - `destroy()` 释放语言订阅；
- `feature/settings/src/main/ets/pages/SettingsPage.ets`：
  - 接入 `Lang.getInstance()` 监听并支持动态局部刷新；
  - 新增 `LanguageCardView` 与 `LanguageOption` 分段切换组件（System / English / 简体中文）；
  - 全页文案资源化（`this.t('...')`），严格遵守设计系统 tokens。
- `feature/settings/src/test/SettingsReducer.test.ets`：
  - 新增语言切换与状态一致性测试。
