## 核心修改清单

### 1. 领域层置顶方法与实时事件流
- `core/domain/src/main/ets/chat/MessageProjection.ets`：

  - 提供 `pinChatMessage(chatId, messageId, disableNotification = false, onlyForSelf = false)`；
  - 提供 `unpinChatMessage(chatId, messageId)` 与 `unpinAllChatMessages(chatId)`；
  - 增加 `pinnedMessageListener?: (chatId: string, messageId: number, isPinned: boolean) => void` 监听回调；
  - 在 `handleUpdate` 中分发 `updateMessageIsPinned`：更新内存中对应消息的 `is_pinned` 标志，并触发 `pinnedMessageListener`；
  - 纯 ArkTS / Kit-free 架构合规实现。

### 3. Reducer 纯函数状态机
- `feature/chat/src/main/ets/reducer/ChatReducer.ets`：
  - `onMessageActionMenuLoaded`: 当 `canBePinned` 且非失败态时设置 `showPin = true`，并解析 `isPinned`（结合已载入标记与当前 Item 标记）；
  - `pinMessage`: 派发 `PinMessageEffect(state.chatId, action.messageId)` 并关闭动作面板；
  - `unpinMessage`: 派发 `UnpinMessageEffect(state.chatId, action.messageId)` 并关闭动作面板。
- `feature/chat/src/test/ChatReducer.test.ets`：
  - 新增 3 组单元测试：

    - `unpinMessage_emitsUnpinMessageEffectAndDismissesMenu`
  - 验证通过（`feature_chat` 模块单测全部通过）。

### 4. Coordinator 副作用与实时联动
- `feature/chat/src/main/ets/coordinator/ChatCoordinator.ets`：
  - `start()` 中向 `MessageProjection` 注册 `setOnPinnedMessageChanged`，一旦置顶消息发生变动自动触发 `this.fetchPinnedMessage()`；
  - `resolveMessageItem` 与 `mapAlbumToItem` 装配 TDLib 消息 `is_pinned` 到 `MessageItem`；
  - `getMessageProperties` 异步完成时回灌 `props.can_be_pinned` 与 `cachedMsg.is_pinned` 到 `OnMessageActionMenuLoaded`；
  - `executeEffect` 中处理 `pinMessageEffect` 与 `unpinMessageEffect`：调用领域层 API，并在执行成功后调用 `this.fetchPinnedMessage()` 同步顶栏。

### 5. UI 渲染与交互走查
- `feature/chat/src/main/ets/pages/ChatPage.ets`：
  - `messageRowKey` 引入 `item.isPinned`，确保置顶态变更驱动列表行精准局部刷新；
  - `ActionMenuSheet`：在 `menu.showPin` 时渲染矢量图标 `ic_pin` 与文案 `Pin` / `Unpin`；
  - `PinnedMessageBar`：支持点击正文区域触发 `ScrollToMessage` 居中高亮；点击右侧 ✕ 按钮触发 `UnpinMessage` 解除置顶。

## 模拟器走查与真机证据

1. **呼出菜单**：长按目标消息，弹出 `ActionMenuSheet`，快捷表情栏下方依次展示 `Reply`, `Copy`, `Copy Link`, `Forward`, **`Pin`**（原生 `ic_pin` 矢量图标）与 `Delete`。
2. **置顶操作**：点击 `Pin` 选项，TDLib 发出 `pinChatMessage` 请求并成功响应。
3. **置顶横条上屏**：顶部实时出现 `PinnedMessageBar`（左侧蓝色垂直指示条、`Pinned Message ∨` 标题、消息摘要正文、右侧 `✕` 解除按钮）。
4. **状态反转**：再次长按该置顶消息，菜单项动态变为 **`Unpin`**。
5. **解散置顶**：点击顶栏右侧 `✕` 按钮，顶栏收起，置顶状态恢复平铺。
